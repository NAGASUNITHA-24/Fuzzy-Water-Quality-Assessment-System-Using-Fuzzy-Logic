# 💧 Fuzzy Water Quality Assessment System

## 📌 Project Overview

The **Fuzzy Water Quality Assessment System** is an intelligent decision-support system developed using **Python** and **Fuzzy Logic**. The project evaluates water quality based on important parameters such as **pH**, **Dissolved Oxygen (DO)**, and **Turbidity**, and predicts the **Water Quality Index (WQI)**.

Unlike traditional methods that rely on fixed thresholds, this system uses a **Fuzzy Inference System (FIS)** to handle uncertainty and provide a more realistic assessment of water quality.

---

## 🎯 Objectives

- Predict the Water Quality Index (WQI) using fuzzy logic.
- Evaluate water quality based on multiple parameters.
- Handle uncertainty in environmental data using fuzzy inference.
- Provide an intelligent decision-support system for water quality assessment.

---

## ✨ Features

- Water Quality Index (WQI) Prediction
- Fuzzy Logic-Based Decision Making
- Interactive User Input

- Data Analysis and Visualization

## 📊 Input Parameters

The system uses the following water quality parameters:

- pH
- Dissolved Oxygen (DO)
- Turbidity

---

## 📈 Output

The system predicts the **Water Quality Index (WQI)** and classifies water into one of the following categories:

- Very Poor
- Poor
- Moderate
- Good
- Very Good
